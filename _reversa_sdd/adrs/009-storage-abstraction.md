# ADR-009: Storage Abstraction and GCP-Native Deployment Guardrails

> Generated by Reversa (Detective) on 2026-04-28
> Level: Detailed

## Context
Data persistence initially relied on local storage (Parquet/DuckDB), which is volatile in serverless runtimes like Google Cloud Run.

## Decision
Abstract data storage to support S3/GCS backends alongside local files, ensuring compatibility with containerized deployment strategies.

## Alternatives Considered
1. **Persistent Volumes (PVs)**: Complex to maintain in Cloud Run.
2. **Stateful database instances**: Higher cost for OLAP workloads.

## Consequences
- **Positive**: Enables stateless deployment and high horizontal scalability.
- **Negative**: Requires anti-corruption logic for local-to-remote synchronization.
