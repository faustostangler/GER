| Token | Cor | Uso | Confiança |
| :--- | :--- | :--- | :--- |
| `--background` | `#0d1322` | Deep Nocturnal Navy (Fundo principal) | 🟢 |

| `--primary` | `#adc6ff` | Surgical Blue Focus (Destaque, foco, botões primários) | 🟢 |
| `--primary-glow` | `rgba(173, 198, 255, 0.25)` | Efeito de brilho/glow para foco | 🟢 |
| `--secondary` | `#6ddd81` | Precise Green (Sucesso, métricas positivas) | 🟢 |
| `--tertiary` | `#fbbc06` | Diagnostic Yellow (Alertas, avisos como Amber Alert) | 🟢 |
| `--error` | `#ffb4ab` | Critical Red (Erros, falhas de autenticação) | 🟢 |
| `--on-surface` | `#dde2f8` | Soft Technical Gray (Texto principal) | 🟢 |
